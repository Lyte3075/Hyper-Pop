# Hyper-Pop ✦
A playful collection of tiny games, useful-ish tools, doodles, and internet experiments.

## GitHub Pages
This is a static, dependency-free site. The entry point is `index.html`.

### Included
- 🎮 Reaction Rush
- 🖱️ Button Bonanza
- 🪙 Coin Flip
- 🎲 Dice roller
- 🎯 Random choice picker
- 🌈 Palette generator with copy-to-clipboard
- 🎨 Touch/mouse doodle canvas + PNG export
- ⏱️ Mini stopwatch
- 🪄 Random thought machine
- 🚨 A button you probably should not press

Built to be expanded with more games, experiments, generators, and delightfully unnecessary internet objects.
