How to call a route

Use the generated URL from your app and include your Hyper-Pop session token in the Authorization header. The route only works for the account that created it.

fetch("YOUR_ROUTE_URL", {
  headers: {
    Authorization: "Bearer " + hyperpopToken
  }
})

Security: HTTPS origins only, public DNS required, private/reserved addresses blocked, redirects restricted to the configured domain, credentials stored in Vault, and account-scoped route access. Shared/public routes and custom vanity domains are not part of this phase.
