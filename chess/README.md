# Chess for Hyper-Pop

This folder contains the Static Chess game integrated into Hyper-Pop.

- Upstream project: https://github.com/TMHSDigital/Static_Chess
- Upstream author: TMHSDigital
- License: Apache License 2.0 (see `LICENSE`)
- Runtime: vanilla HTML, CSS, and JavaScript; no runtime package install is required.

The game is served from `chess/index.html`. Its CSS and JavaScript remain inside this folder so its implementation is isolated from the rest of Hyper-Pop.
